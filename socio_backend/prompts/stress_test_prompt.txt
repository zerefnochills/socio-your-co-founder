## STRESS TEST FRAMEWORK

Run the following analysis in order. Be specific to THIS startup — no generic frameworks.

### 1. ASSUMPTION EXTRACTION
List the 5-7 most critical hidden assumptions this business is built on.
These are the beliefs that must be true for the startup to succeed — most of which the founder has never explicitly stated.

Format each as:
- Assumption: [the belief]
- Risk level: HIGH / MEDIUM / LOW
- How to validate cheaply: [one specific action to test it]

### 2. KILL SHOTS
What are the 3 most likely ways this startup dies? Be specific. Not "competition" — name the competitor. Not "no product-market fit" — describe exactly what scenario kills them.

For each:
- Kill shot: [how it dies]
- Probability: HIGH / MEDIUM / LOW
- Defence: [what the founder should do now to reduce this risk]

### 3. MOAT ANALYSIS
Rate the defensibility of this business across 4 dimensions:
- Network effects (does it get stronger as more people use it?)
- Switching costs (how hard is it to leave?)
- Data advantage (does it accumulate data that improves the product?)
- Brand / trust (would users stay even if a clone existed?)

Score each 1-5. Give one-sentence reasoning per dimension.

### 4. MARKET REALITY CHECK
- Is the market large enough? (Don't accept "trillion dollar market" framing — what's the realistic serviceable market in year 3?)
- Is the timing right? (What has changed recently that makes this the right moment?)
- Is there evidence of demand that isn't manufactured? (What's the pull signal?)

### 5. FOUNDER-MARKET FIT
One honest paragraph: why is THIS founder positioned to win in this space? What do they bring that makes them specifically dangerous? Be direct about gaps too.

### 6. SCORECARD

Score each dimension 1-10:

| Dimension | Score | Verdict |
|---|---|---|
| Problem severity | /10 | |
| Market size | /10 | |
| Defensibility / moat | /10 | |
| Timing | /10 | |
| Founder-market fit | /10 | |
| Traction signal | /10 | |
| Monetisation clarity | /10 | |

Overall score: /70

### 7. VERDICT

One of:
- STRONG SIGNAL — Ship fast, your biggest risk is speed
- PROCEED WITH CAUTION — Core thesis holds but [X] must be resolved in 60 days
- PIVOT NEEDED — The problem is real but this solution approach has a structural flaw. Consider [specific alternative direction]
- KILL IT — Here's the honest reason why, and here's what to build instead

Follow the verdict with 3 specific, actionable next steps — numbered, one sentence each.
